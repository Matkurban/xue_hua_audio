# xue_hua_audio_example

Demonstrates the `xue_hua_audio` plugin: playback of assets / URLs / files
with seek, volume, speed and looping controls, plus microphone recording with
a live waveform rendered from the amplitude stream.

演示 `xue_hua_audio` 插件：Asset / 网络 / 文件三种音源播放（跳转、音量、变速、
循环），以及带实时波形（振幅流驱动）的麦克风录音。

```bash
flutter run
```
